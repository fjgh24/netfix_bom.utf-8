# NetFix Toolbox
A pure Windows batch toolkit providing two main features: **Hardware Inventory** and **ISO Download**, with a bilingual (CN/EN) menu.
## Features
### 1. Hardware Inventory
- Internal: CPU, Memory, Storage, BIOS Firmware, GPU, Motherboard, Model, Network Adapter, Audio, OS
- External: Monitor, Keyboard, Mouse, Printer, USB Devices
All queries are read-only — nothing on your system is changed.
### 2. ISO Download
Built-in download links for multiple OS editions:
- Windows
- Linux
## Requirements
- OS: Windows 7 / 8 / 10 / 11
- Dependency: PowerShell 2.0 or later
- Privilege: No admin rights required (read-only)
## Usage
1. Download the main .bat file
2. Double-click to run, or execute in cmd
3. Select a feature from the menu
## Notes
The script contains Chinese text

# NetFix 工具箱
一个纯批处理形式的 Windows 系统工具箱，提供「硬件扫描」与「系统 ISO 下载」两大功能，支持中英文双语菜单。
## 功能特性
### 1. 硬件扫描
- 内部硬件：CPU、内存、存储、BIOS 固件、显卡、主板、机型、网卡、声卡、操作系统
- 外部设备：显示器、键盘、鼠标、打印机、USB 设备
全部为只读查询，不会修改任何系统设置。
### 2. 系统 ISO 下载
内置多版本系统下载入口：
- Windows
- Linux
## 系统要求
- 系统：Windows 7 / 8 / 10 / 11
- 依赖：PowerShell 2.0 及以上
- 权限：无需管理员（仅读取硬件信息）
## 使用方法
1. 下载主程序 .bat 文件
2. 双击运行，或在 cmd 中执行
3. 根据菜单选择功能


## 注意事项
脚本含中文
